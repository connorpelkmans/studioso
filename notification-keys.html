Notification Keys

Makes the keys that let Studyboard send reminders to phones and computers while the app is closed. You only need to do this once for everyone. Nothing leaves this page.

  1. In your server's dashboard, open Edge Functions, then Secrets, and add the three values above with the names shown (use your own email in the Contact).
  2. Open SQL Editor, paste the SQL and click Run.
  3. Make sure the send-reminders function is deployed with Verify JWT off (see Reminders in the setup guide).
