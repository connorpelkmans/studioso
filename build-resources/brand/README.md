The wordmark with the Studyboard mark as its S, from `website/assets/logo-dark.webp` and `logo-light.webp` (transparent PNG).

- `studyboard-logo-white.png`: for dark backgrounds (the Studyboard navy, Stripe Checkout's branding)
- `studyboard-logo-navy.png`: for light backgrounds
- `-padded` versions have room around the logo, for places that crop tightly
