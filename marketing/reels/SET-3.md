# Set 3: designed from everything so far (Nov 19, 2026)

## What the data and feedback taught us
| Lesson | Evidence | What Set 3 does |
|---|---|---|
| The opening is the whole game | D: 107 viewers, 5 s average watch; Connor: "hook must grab in 2 s" | Something lands at frame 0; new onsets every 0.3–0.5 s until about 2 s |
| Polish reads as an ad | Connor; the format outliers were one shot, static text, music only | Phone UIs people see every day; music only; no logo cards |
| Native held a bigger share | Native post: 53% watched (D: 29%), 1.8 views per viewer | Kept: 5–6 s, loops, static text |
| A demo gives nothing to react to | Native post: 0 organic likes, comments or shares | Every reel has a reason to comment or send |
| Long hooks get read, then skipped | 4 s average watch ≈ the time to read a 14-word hook | Hooks of 4–7 words |
| No stock people | Connor, Nov 19 | Everything animated, or the real app |
